# Product Manager

Administrative web application to manage products with local persistence.

## Features
- CRUD operations
- Soft delete
- Search and sorting
- Modular architecture
- Responsive UI

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage

## Architecture
MVC-inspired modular structure.
